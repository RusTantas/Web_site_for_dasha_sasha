# Свадебный сайт-приглашение: Дарья & Александр

Статический сайт-приглашение на свадьбу для Дарьи и Александра (21 июня 2026).

## Особенности

- **Светлый минималистичный дизайн**: кремовый, шампань, нежно-песочный + фиолетовые акценты
- **Адаптивный**: корректно отображается на мобильных устройствах и десктопе
- **Обратный отсчёт**: до 21 июня 2026 года
- **Форма регистрации гостей**: имя, фамилия, количество персон, контакт, пожелания, выбор напитков
- **Сохранение данных**: localStorage (данные не сбрасываются после перезагрузки)
- **Декоративные элементы**: фиолетовые цветочные узоры по бокам (статичные, остаются на месте при скролле)
- **Редактируемый текст**: основные текстовые блоки можно редактировать прямо на странице

## Админ-панель

Доступна по кнопке "⚙ Панель управления" внизу страницы.

- **Логин**: `DARIY`
- **Пароль**: `SASHA`

**Функции админ-панели:**
- Просмотр списка всех зарегистрированных гостей
- Фильтрация по имени, фамилии или контакту
- Просмотр статистики (количество гостей, персон, типов напитков)
- Удаление гостей
- Экспорт данных в CSV

## Файлы

- `index.html` — основной файл сайта
- `style.css` — стили (светлый минимализм, фиолетовые акценты)
- `script.js` — логика (форма, админ-панель, localStorage)
- `wedding-complete.html` — самодостаточный файл (всё в одном, можно открыть локально без сервера)

## Как использовать

### Вариант 1: Открыть локально
Скачайте `wedding-complete.html` и откройте в любом браузере (двойной клик по файлу).

### Вариант 2: Разместить на хостинге
Загрузите `index.html`, `style.css` и `script.js` на любой статический хостинг (GitHub Pages, Netlify, Vercel и т.д.).

## Технологии

- HTML5 + CSS3
- Vanilla JavaScript (ES6+)
- localStorage для хранения данных
- Google Fonts (Inter)
- Без внешних зависимостей и библиотек

## Настройка

Основные параметры можно изменить, отредактировав текст прямо на странице (все текстовые блоки доступны для редактирования).

Для изменения логина/пароля админа измените переменные `ADMIN_USER` и `ADMIN_PASS` в файле `script.js`.
